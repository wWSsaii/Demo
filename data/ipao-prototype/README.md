# i跑校园 · HTML 交互原型

## 文件说明
- `index.html`：原型主文件，使用浏览器打开即可预览。
- `i跑校园*.jpg`：17 张小程序现有截图，作为各页面底图。

## 如何查看
1. 直接双击打开 `index.html`（推荐用 Edge/Chrome）。
2. 或在当前目录运行本地服务器后访问：
   ```bash
   python -m http.server 8126
   # 浏览器打开 http://localhost:8126
   ```

## 原型结构
本原型共 22 个页面：
- **现有截图页面（17）**：首页、圈子、流量卡、网课代刷、零食团购、接送服务、技能墙、宿舍美甲下单、游戏陪练下单、租车、任务大厅、网课卡购买、龙昆南美食、确认订单、聊天、待确认完成、快递代取(桂)。
- **新增补全页面（5）**：发布需求、需求详情、支付成功、我的订单、我的。

## 核心可点击流程
1. **首页 → 发布需求 → 需求详情 → 确认订单 → 支付成功 → 我的订单**
2. **首页 → 各服务入口 → 服务详情 → 确认订单 → 支付成功**
3. **首页底部 Tab**：首页 / 圈子 / 订单 / 我的
4. **任务大厅 → 任务卡片 → 待确认完成 → 我的订单**

## 注意事项
- 截图页面使用透明热区覆盖，点击对应区域即可跳转。
- 新增页面为 HTML/CSS 绘制，风格与现有截图保持一致。
- 若要在墨刀中使用，可将本原型在浏览器中截图后导入墨刀，再手动添加跳转热区。
